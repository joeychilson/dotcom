# joeychilson.com

My personal website and writing archive.

## Development

```sh
pnpm install
pnpm dev
```

Run checks and create a production build with:

```sh
pnpm check
pnpm build
```

Writing is stored as Markdown in [`src/writings`](src/writings). Add `draft: true` to a post's
frontmatter to show it locally without publishing it.
